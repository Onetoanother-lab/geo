# Assets: origins and licences

Every visual and sound in the presentation is either created for this project or comes from an openly licensed package bundled at build time. Nothing is loaded from the internet at runtime.

| Asset | Where | Origin | Licence / attribution |
|---|---|---|---|
| Forest, trees, roots, saxaul, landscapes, animals, ship, icons | `src/lib/forest/*`, `src/components/visualizations/*`, scene SVGs | Original procedural / hand-written SVG made for this project | Project's own work, no attribution required |
| Ambient audio (forest bed, birds, insects, wind, tree-fall) | `src/lib/audio/engine.ts` | Synthesized at runtime with the Web Audio API | Project's own work |
| Optional recorded loops | `public/audio/forest-loop.mp3`, `public/audio/wind-loop.mp3` (not included) | Add only CC0 / royalty-free recordings | Record the source and licence in this table when adding files |
| World countries (110m) | `world-atlas/countries-110m.json` (npm) | Natural Earth vector data, redistributed as TopoJSON by world-atlas | Natural Earth: public domain. world-atlas: ISC. Credited in the finale |
| Aral Sea shorelines | `src/scenes/Aral/AralMap.tsx` | Hand-drawn **schematic** outlines based on the shoreline sequence in NASA Earth Observatory "World of Change: Shrinking Aral Sea" | Project's own drawing; labelled on screen as schematic ("Sxematik tasvir — aniq xarita emas") |
| Fraunces (variable) | `@fontsource-variable/fraunces` | Undercase Type | SIL Open Font License 1.1 |
| IBM Plex Sans, IBM Plex Mono | `@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono` | IBM | SIL Open Font License 1.1 |
| Favicon | inline data URI in `index.html` | Original | Project's own work |

Notes:
- **Uzbek glyphs:**
  - Fraunces does not contain U+02BB (ʻ), so all copy uses U+2018 (‘) for o‘/g‘, which all three fonts support (enforced by a unit test).
  - The → arrow is also missing, so arrows are drawn as SVG.
- **Replacing art:** the procedural art is generated by components with stable props, so final illustrations can replace them without restructuring scenes. Keep the `.fs-depth` wrappers and class names that the timelines target.
- **Adding a photograph or recording:** it must be public domain, CC0/CC-BY with attribution recorded here, or explicitly licensed. Never use scraped images or commercial music.
